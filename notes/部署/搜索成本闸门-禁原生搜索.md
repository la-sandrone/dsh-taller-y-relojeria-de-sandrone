## 三 · 官方口径（2026-10-20 实抓，不是回忆）

**DeepSeek**（`api-docs.deepseek.com/zh-cn/guides/search` 的「计费」节 + `quick_start/pricing` 的「网页搜索与抓取价格」）：

- Search 5 元/千次、Fetch 5 元/千次，**按请求次数**，不按 token、不按结果条数；`count` 不影响价格。
- **只有 HTTP 200 且确实产生结果**的请求计费；失败、无结果、超时**不计费**。
- 「当前用户在 DeepSeek Harness / Claude Code / Codex 中使用 DeepSeek API 时，已经会通过 **Server 端工具调用**访问到 Search/Fetch 接口，这部分目前未计费，并将于**北京时间 2026-11-01 00:00** 起按次收费。」
- ⚠️ **直连 API 没有宽限承诺，而且已实测确认它在扣费**：宽限只写在「Server 端工具调用」这一条上；直连 `/v1/tools/search` 是本次「正式向公众开放」的付费接口。本机两轮各 60 次的实测是 **0.0055 元/次**（见第四节）⟹ **打开即付费，从第一天起**。

**DSH 0.2.1**（`packages/web/web-deepseek-api/README.zh.md`、`packages/web/tool-web/README.zh.md`、`packages/bundle/base/cordis.patch.yml`）：

- `web` 服务两个独立开关：`searchProvider` / `fetchProvider`。
- 旧默认：`deepseek-official`（Messages 服务端搜索，**一次搜索 = 一整轮辅助模型请求**）+ `http`（本地匿名抓取，**免费**，只接受公开 HTTP(S)，遇反爬必失败）。
- 新路：`deepseek-search-api` + `deepseek-fetch-api`（直连，**无模型轮次**）。
- **provider 之间没有自动重试、没有回退**——「免费优先、付费兜底」不可能由配置表达，只能靠纪律（见下节）。
- `web_search` 一次调用可带最多 `searchMaxQueries` 个 query，并发扇出 ⟹ **一次工具调用最多 N 次计费**。本机已压到 3。
- `web_fetch`：超时 30s、单次输出上限 20 万字符；非 2xx 会在结果里报告，不抛错。

## 四 · 成本算术与一次实测

| 场景 | 花费 |
|---|---|
| 单次成功搜索 / 抓取 | 0.005 元 |
| 一次 `web_search`（3 query 全中） | 0.015 元 |
| 一场调研（50 搜索 + 100 抓取） | 0.75 元 |
| 1000 次 | 5 元 |

**实测（2026-10-20 17:5x，`tools/check-search-billing.py`，全部 HTTP 200 且结果非空）**：

| 轮次 | 次数 | 余额变化 | 折算 |
|---|---|---|---|
| 首测（观察窗口 5s） | 12 | `135.02 → 135.02` | 未显形（结算滞后） |
| 第二轮（隔离窗口 60s） | 60 | `134.55 → 134.21` = **0.34 元** | 0.0057 元/次 |
| 第三轮（紧接着） | 60 | `134.21 → 133.88` = **0.33 元** | 0.0055 元/次 |

- **结论：直连 Search API 现在就在扣费**，两轮独立测量一致落在 0.0055 元/次，与官方 5 元/千次吻合（略高一点，视为上浮/结算含尾差）。
- 第一轮 12 次「没看见扣」是**结算滞后**，不是免费 —— 这就是为什么单次小批量测不出来，至少 60 次才稳。
- 另有一个副作用值得记住：**余额会同时被本会话的模型 token 消耗推动**。要核查搜索计费，必须在**同一条命令内**读完余额→打完请求→再读余额（脚本就是这么做的），中间不夹模型回合。
- 本次核查总花费：133 次调用 ≈ **0.73 元**。
- 脚本：`tools/check-search-billing.py`（默认干跑只读余额；`--apply` 才真打）。

## 五 · 使用纪律（比配置重要）

**内置 web 工具是付费路，排在最后。** 顺序固定为：

1. **免费 MCP 先上**：`mcp__bingcn__bing_search`（中文检索）、`mcp__cloakbrowser__fetch`（stealth 浏览器，能过不少反爬）、`mcp__linkdigest__*`（社媒链接）。
2. **需要这些能力时才动内置**：
   - 免费路失败 / 空结果 / 被反爬挡住；
   - 需要 `site:` / `lang:` / `after:` / `before:` / `-site:` 这类高级检索语法（bingcn 给不了）；
   - 需要服务端渲染、且 cloakbrowser 也拿不到正文的硬站。
3. **禁止**：用内置搜索做廉价重复搜索、拿它当默认检索、一次调用塞满 query 做穷举。

> 这条纪律没有技术强制。谁能读到本文件、读到 `AGENTS.md`，谁就受它约束——这是它存在的唯一理由。
