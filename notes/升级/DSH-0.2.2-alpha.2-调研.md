# DSH v0.2.2-alpha.2 调研

> 2026-11-01 起稿。用途：判断 11 月 4 日（原神大版本同日）该升到哪个版本。
> 结论先行：**改成追 `0.2.2-rc`——出了就动，不出不动。**
> 理由：这一版有六条「日常磨损级」修复（Windows 路径、单个 `~`、Git 走 SSH 等），
> 值得为它打破 42 天卡池节奏。详见第五节。

### 和你的痛点直接相关的

## 五、策略：改成追 `0.2.2-rc`（2026-11-01 定）

### 为什么破例

**常规节奏是 42 天一次（跟原神卡池周期走）**，但 `0.2.2` 里有**六条日常磨损级**的修复，值得为它提前动：

| # | 修复 | 影响频率 |
|---|---|---|
| 1 | **Windows 路径反斜杠不再被转义删除** | **天天**（WSL + Windows 混合环境） |
| 2 | **单个 `~` 保持字面，`~~` 才是删除线** | 高频（写路径/代码） |
| 3 | **自托管 Git：HTTPS 读不了自动改用 SSH** | 中频（装 `github:` 源插件时） |
| 4 | 含 `prepare` 脚本的插件安装显示授权和重试 | 中频 |
| 5 | 本地 Markdown 图片覆盖后显示新图 | 中频（素材重做） |
| 6 | **触屏动作不被悬停提示阻挡** + **宽表格局部滚动** | 手机端日常 / **对应两个皮肤补丁** |
| 7 | **修复跨行 `$$` 数学块渲染**（保留首行公式 + 公式后正文） | 写公式时 |
| 8 | **修复裸 URL 吞掉后续中文标点与正文** | **中文环境每天** |
| 9 | **修复结构体代码高亮导致页面长时间卡死** | **偶发但致命** |
| 10 | 相对文件链接按会话工作目录打开（worktree 后不误开原项目） | 多 worktree 时 |
| 11 | **工作步骤收起后保留全部助手文字回复，可切换「仅最终回答」** | **每轮都在用** |
| 12 | **断线或重连期间暂停聊天运行计时**，恢复后按轮次起点显示 | **弱网环境通用** |
| 13 | **停止后补发的插话与新消息按日志顺序显示**，刷新/历史加载后一致 | **弱网环境通用** |

**「日常磨损」和「偶发 bug」不是一个量级**——前两条每天都在磨，值得为它们打破 42 天节奏。

> ⚠️ 第 9 条要单独留意：**「代码高亮导致页面长时间卡死」和「网络卡死」症状极像**。
> 2026-11-01 那天把手机端卡死诊断成 WS 问题，但根因可能是这条。升级后若仍卡，先查它。
>
> **第 11 条是最磨人的一条**：助手在工具调用之间说的话（"我需要确认一下"、"这里有两个方案"）
> 全被折叠进「工作步骤」，收起即消失——**人和助手的对话被折叠吞掉了**。
> 用户想「再看看过程」时无过程可看。这条改的是「折叠只折叠工具调用，不折叠助手文字」。
>
> **第 12、13 条是弱网环境通用福利——手机和电脑都吃到**。
> ⚠️ 别以为只跟国际链路有关：**DeepSeek 是国内企业、国内服务器，但中国移动这条线连国内 API 也抖**
> （"聊几条消息网络就得挂一会儿"），本工作区的 `dsh-force-h1` / `dsh-fetch-trace` 两个 preload
> 就是为这个打的，不是为 Cloudflare。两处断的是同一类事：**链路会断，恢复后状态得对得上**。
>
> 实测：公网隧道 WS 成功率四到五成。
> - 12：断线时计时还在跑，重连后显示"已运行 12 分钟"（其实断了 5 分钟）——**计时错会误导判断**，
>   让人以为模型慢，其实是网络在磨。
> - 13：断线时发的插话，重连后顺序可能乱——**你说的话应该出现在它回的话之前**，
>   否则读起来像「它先答了，你后问的」。

### ✅ 升级后必验：两个皮肤补丁可以撤吗

**0.2.2 的第 6 条一次覆盖两个皮肤补丁**（都是「CSS 绕过」→「官方在 DOM 层修掉」）：

| 皮肤补丁 | 官方修复 | 升级后动作 |
|---|---|---|
| `[class*="_bubble"][role="tooltip"]{display:none}` | 触屏动作不再被悬停提示阻挡 | **先撤掉试**，tooltip 在手机上有用 |
| `md-table-wide` 强制压缩 | 宽表格在局部容器滚动 | **验证能滚就撤** |

> tooltip 那条当年是「把 tooltip 整个关掉」换来的——代价是桌面端也没了。
> 官方修法应该是「触屏不响应 hover」，比我们温和。

### ✅ 升级后必验：宽表格「压缩 vs 滚动」

**这是唯一一条可能和我们自己皮肤补丁打架的更新。**

> 0.2.2-alpha.2：宽 Markdown 表格在局部容器中滚动（触屏） `@Stevring`

**背景**（见 `皮肤/皮肤主题笔记.md:71-81`）：我们当年修宽表格时，试过滚动但**放弃了**——

> `overflow` 对 `display: table` 元素无效（CSS 规范：只适用于块/flex/grid 容器）——
> **表格滚动必须靠包裹 div**，`<table>` 本身加 overflow 永远无效。
> 滚动方案在 Firefox 不可靠，**最终用强制压缩**。

**根本原因**：插件只能注入 CSS，**包不了 div**；官方能改 DOM，所以能做滚动。

**所以升级后要验一件事**：

| 现象 | 动作 |
|---|---|
| 官方真的包了容器、表格**能滚** | **删掉皮肤里的强制压缩规则**（`md-table-wide` 那块），滚动体验更好 |
| 表格**不能滚**（只做了半截） | 压缩规则保留，否则长表格又溢出 |

**不验的后果**：两套规则同时存在，**压缩压扁了本来能滚的表格**，或者两样都没生效。

## 八、上游跟进：HTTP/2 毒化（2026-11-01 已行动）

### 已做

在 `#6935` 下补了一条评论（**国内链路同样中招** + 已实践数月 + 强调「进程级不可恢复」）：

https://github.com/deepseek-ai/deepseek-harness/discussions/6935#discussioncomment-19324716

### 判据：什么时候升级成主题贴

| 时点 | 动作 |
|---|---|
| `0.2.2-rc.1` 出来时 | 查 `@deepseek-ai/dsh-http-proxy` 有没有 `allowH2: false` 或开关 |
| **没修** | **发主题贴** |
| 已修 | 关掉这条跟进 |

**发主题贴不算刷屏**（2026-11-01 定）：

- **评论不会被搜索到**——遇到 `ERR_HTTP2_INVALID_SESSION` 的人搜错误码，搜不到 #6935 底下的评论
- **这是默认值问题，不是个人环境问题**——`allowH2` 默认 `true` 影响每个用户，不该只挂在一条 case 底下
- **主题贴能带可执行诉求**（装 dispatcher / 给开关），评论只能附和

**发法**（避免被判重复）：
1. 标题带**错误码 + 后果**，不用「我也遇到」
2. 第一段**引用 #6935**：「延续其发现，本文聚焦不同维度」
3. **增量在影响面 + 用户可诊断性 + 默认值**，不复述机制
4. 结尾给明确行动请求

### 为什么值得单独发贴

**这是可靠性问题，不是性能问题**：

```
性能问题：慢一点，能用        → 用户能忍
可靠性问题：卡死，只能重启    → 重启丢掉正在跑的会话 → 用户不能忍
```

**而且可诊断性极差**：现象是 `fetch failed`，必须挖到 `error.cause` 才看得见
`ERR_HTTP2_INVALID_SESSION`。**普通用户永远查不到这一层**，只会觉得「DSH 又崩了」。

**这条如果不上，用户侧永远归因不到「h2 会话复用」这个根因上。**
