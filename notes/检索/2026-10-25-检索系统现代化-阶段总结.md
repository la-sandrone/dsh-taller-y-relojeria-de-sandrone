## 三条主线

### ① CJK 检索：jieba → unigram + bigram

**为什么**：jieba 词典覆盖头部，自造词/术语切错边界（`布恩迪亚计算机`、`火用`），
实测约 30% 漏搜；而 `innodb_ft_min_token_size` 默认 3 会丢掉所有 1–2 字中文词。

**依据**：Lucene `CJKBigramFilter(outputUnigrams=true)` / ES `cjk_bigram`；SIGIR'98 Nie & Ren。

**结果**：`绘` 命中 5,976、`拜占庭`（→ `+拜占 +占庭`）1,375、`口径` 263，
与 LIKE 逐条对拍一致。

### ② 向量化：dsh_message 补 embedding

**口径**（用户拍板）：只嵌 `assistant/message` + `user/message` 两类正文，
共 27,495 行 / 12.7 M 字符。reasoning 占 39% 字符但语义价值低于结论，排除。

**结果**：24.4 分钟完成，零失败。`dsh_message` 已有 33,993 行带向量
（含早期宽 scope 顺带嵌的 6,290 条 `agent/inbox/spliced`，无害）。

### ③ 多语言：Unicode 边缘修正

**触发**：古典学专著里有成批俄文（`Византийская библиотека`）、希腊文、
带变音拉丁文。而 tokenizer 的非 CJK 分支只认 `[A-Za-z0-9_]+`。

**修正**：改成两段 alternation（`([CJK]+)|(\w+)`，顺序即优先级），
西里尔/希腊/变音拉丁全部保住，`café` 不再被拆成 `caf` + `é`。

## 踩坑清单（按「教训价值」排序）

### 1. 两次猜错瓶颈，第三次才对

先怪「server_bge 的串行锁」、再怪「上游文本更长」——**都错**。
插三段 `monotonic()` 打点后发现 **73.4% 时间在数据库写回**，
根因是 `body_sha256` **缺索引**（每条 UPDATE 全表扫 14 万行 = 385 ms）。

**而且连磁盘都不是**：buffer pool 命中率 99.73%，整张表在内存里，
瓶颈是「在内存里扫 2.4 GB 宽行」的 CPU/内存带宽。

→ 详见 `等待归因实验-dsh_message嵌入写回.md`

### 2. `+拜占庭` 查不到不是数据问题

bigram 索引里 3 字词只有 `拜占` 和 `占庭`，**没有整词 `拜占庭`**。
必须用 `build_cjk_boolean()` 生成布尔串。

### 3. HNSW 是近似的，而且不告诉你漏了什么

自查询 top-1 只 92%（top-10 100%）。`mhnsw_ef_search` 20→400 无变化。
**不可用于精确查找/判重**。

→ 详见 `MariaDB-CJK全文检索-落地.md` §11.7

### 4. 「俄希拉丁全文路失效」是我判断错了

`col = content_tokenized if is_cjk else content` —— **非 CJK 查询根本不碰
tokenized**，走 `content` 列（空格分词）正常工作。实测俄文 fulltext 命中 48.9。

跨语言语义检索本来就该走向量路（bge-m3 多语言共享空间）：实测中文查
「拜占庭帝国的体育教育与竞技运动」直接命中俄文书对应章节。

→ 因此「重建 tokenized 补俄希拉丁」**不做**，收益近零。

### 5. MariaDB 与 MySQL 的微妙差异

- FULLTEXT 的 `ALGORITHM=INPLACE` 在 MariaDB 上**仍 rebuild 整表**
- 同语句 `DROP INDEX a, ADD FULLTEXT a(...)`（定义相同）**被优化成空操作**，必须拆两条
- `SET GLOBAL innodb_ft_min_token_size` **静默成功但不生效**（startup-only）
- `GRANT ... ON db_name.*` 里的 `_` 是**通配符** → 会多出一行未转义记录，
  两行并存时只命中其中一行，导致「GRANT 了却不生效」

### 6. `SET col = col` 不能用来测写入性能

无变化更新可能被优化掉，也可能只是省了索引维护但扫描照做。

### 7. 默认值是按「英语 + 网页 + 头部覆盖」调的

`min_token_size=3`（丢两字中文）、jieba 词典（丢自造词）、
`[A-Za-z]`（丢西里尔/希腊/变音）、`mhnsw_default_distance=euclidean`（静默降级）。

### 8. 字素簇是最小正确切分单位

`len("👨‍👩‍👧‍👦")` = 11（码点），用户看到的是 1 个字符。
按码点切块会把 emoji ZWJ、组合重音、天城文连字切成两半。

### 9. 后台任务要能被打断、能续传

Windows 自动更新随时杀进程。设计时就要有幂等 + 水位线
（`_shadow_progress` 表救了 17 GB 的重搬）。
