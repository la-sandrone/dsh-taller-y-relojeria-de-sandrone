# 嵌入能力边界：双塔与交叉编码器都抓不到「跨域同构」

## 一句话

**embedding 与 cross-encoder 都无法区分「跨域同构」与「完全无关」**——前者排序反向，
后者直接归零。所以在这类任务里：**余弦是平凡度指标，不是相关度指标**；
而真正能做这件事的是 LLM，因为它**生成**解释而不是比较向量。

---

## 一、问题从哪来

整理一批个人对话导出数据时，要做「剪报」式的素材关联：把两件发生在完全不同领域、
但**结构与功能同构**的事情配成一对。

一个真实例子（用户自己做的）：

> 特朗普「一小时赢赢赢」（白宫官网循环播放、App 内置「史上最伟大总统」按钮、
> AI 生成 cosplay 耶稣画像）
> ↔ 曹操的表演（陈建斌哭父时「呱——呕——」、官渡战前企鹅步、听荀彧建议时「汪！汪汪！」）
>
> 人的判断：这两件事是同一件事——**权力叙事在自我神化，以及它在崩溃时发出的声音**。

字面上这两段**没有一个共同实词**，所以 TF-IDF 一路必然抓不到（被数据证实，见 §三）。

于是问题变成：**理论上这是隐式语义向量的主场，实际能抓到吗？**

「理论上」不算数，于是做了两组实验。

---

## 二、实验设计（可复现）

固定一个锚点，与 6 条**按人类判断的距离排序**的文本比分数；同时用字符 3-gram 余弦
作为 TF-IDF 的替身做对照。**两组实验用完全相同的对照集**，差别只在模型机制：

- **实验 A（双塔）**：`/v1/embeddings` → 各自独立编码 → 算余弦
- **实验 B（交叉）**：`/v1/rerank` → 两段一起送进模型 → 出 relevance_score

**锚点**：特朗普「赢赢赢」段落（白宫官网循环播放 + App 按钮 + AI 画像）。

**候选（按人的判断从近到远）**：

| # | 与锚点的关系 |
|---|---|
| ① | 同一个人同一件事（换措辞复述） |
| ② | 同域·另一个独裁者做类似的事（特鲁希略「上帝在天堂，特鲁希略在人间」+ 全国立雕像） |
| ③ | **跨域同构**·曹操的表演（媒介、时代、语种全不同） |
| ④ | **跨域同构**·《族长的秋天》的文本结构（循环播放一个状态而非叙述故事） |
| ⑤ | 完全无关·闰秒废除与日出日落 API 漂移 |
| ⑥ | 完全无关·聚合物网络裂缝愈合的力学 |

**判据**：如果 ③④ 的分数显著高于 ⑤⑥，说明低分段仍有分辨力；如果重叠，就是抓不到。

脚本：`../tools/probe-embedding-crossdomain.py`、`../tools/probe-rerank-crossdomain.py`
（换模型、换文本、换端点直接重跑）。

## 三、结果

| 候选（人的判断：由近到远） | A·embedding 余弦 | B·reranker 分数 | 3-gram 余弦 |
|---|---|---|---|
| ① 同一人同一事 | **0.7320** | **0.7004** | 0.0555 |
| ② 同域·另一独裁者 | 0.4343 | **0.0000** | 0.0165 |
| ③ **跨域同构·曹操** | **0.3590** | **0.0000** | 0.0000 |
| ④ **跨域同构·小说结构** | **0.3518** | 0.0012 | 0.0313 |
| ⑤ 无关·闰秒与天文 API | **0.4161** | 0.0000 | 0.0000 |
| ⑥ 无关·聚合物力学 | 0.3649 | 0.0000 | 0.0000 |

**两种机制的失败方式完全不同**：

| 机制 | 失败方式 | 证据 |
|---|---|---|
| **embedding（双塔）** | **有信号，但方向反** | 无关文本 0.4161 > 跨域同构 0.3590，间隔 **−0.0644** |
| **reranker（交叉）** | **没信号，直接归零** | 跨域同构与无关**全是 0**，连「同域·另一独裁者」也是 0 |
| TF-IDF（3-gram） | 没信号 | 跨域 0.0313 vs 无关 0.0000，那 0.03 是标点虚词噪声 |

**reranker 比 embedding 更糟**，这一点最反直觉：它有交叉注意力，理论上能看到两段的
角色对齐，实际上它按「这段能不能回答那个 query」判定，输出高度两极化——要么 0.7
（能回答），要么 0（不能），**没有中间态可言**。连 ②（同为独裁者、同类行为、人类看
显然相关）都被判成 0.0000。

---

## 四、为什么 embedding 的方向会反

因为在这个区间，余弦测的主要是**体裁与语域**，不是**意义**。

⑤（闰秒与天文 API）与锚点都是「陈述性说明文」，都以「讲清一件事」的语气行文——
bge-m3 抓住了这个，把它排了上去。而 ③ 是表演描述、④ 是文学分析，文体差得远，
于是被压下去。

bge-m3 的训练目标是**语义相似**：同义改写、复述、问答匹配。所以它做得好 ①
（0.73，识别同一件事的不同说法）——这是它的强项，不是弱点。
但「特朗普神化自己」和「曹操用动物声拆掉权力的庄严」在训练数据里从来没被标成相关，
因为**它们字面上确实不相关**。

---

## 五、那 LLM 是怎么「听懂」的

这是整件事最值得记的一条。**LLM 做的不是匹配，是造桥。**

```
embedding :  A → 向量a ；B → 向量b → 比距离         （没有生成）
reranker  :  (A, B) → 一个分数                       （没有生成）
LLM       :  (A, B) → 「这两件事都是…，因为…」       （生成了一段新文本）
```

**那段解释就是桥。它不在 A 的向量里，也不在 B 的向量里——它是生成出来的第三样东西。**
任何「先各自编码再比较」的方法都找不到它，因为它们的表征空间里根本没有这个位置。

具体到三个例子的槽位对齐：

> 特朗普：用无限重复的「赢」制造现实 ／ 特鲁希略：用改名和雕像制造现实
> ／ 曹操：用动物声拆掉庄严
> → 共同槽位：**权力通过符号操作巩固自身，而符号操作恰恰暴露了它的空洞**

这个槽位在任何一篇原文里都没出现，是三段文本**共同缺失的那块**。

**LLM 凭什么能造出这座桥**：

1. **它见过大量造桥的文本**——文学评论、类比论证、讽刺、脱口秀。它学的是「人类怎么把
   两件事说成一件事」的句式和逻辑动作，不是向量距离。
2. **它的隐空间是过程空间，不是主题空间。** 自回归训练要求它预测「接下来会发生什么」，
   所以它必须编码因果、动机、角色、后果——**这些正是同构需要的槽位**。而检索模型只需要
   编码「这段在讲什么」。
3. **它的中间产物是自然语言，可以直接当工作内存。** 先生成「这两件事都是权力…」，
   再回头修正，直到这句话站得住。这是迭代构造；1024 维向量没有这个能力。

**实用推论**：要找跨域同构，**必须让模型说出理由，而不是让它给分数**。
分数会骗你（0.4161 > 0.3590），理由能被你检查。

## 六、能做什么 / 不能做什么

| 余弦区间 | 实际在测什么 | 能用来干什么 |
|---|---|---|
| **> 0.7** | 同一件事的不同说法 | 去重、找改写、找重复投稿 |
| **0.4 – 0.7** | **体裁与语域匹配**（不是语义） | 慎用。这一档最容易骗人 |
| **< 0.4** | 无分辨力 | 什么都别用 |

| 任务 | 双塔 | 交叉 | 说明 |
|---|---|---|---|
| 去重（同一素材的重复版本） | ✅ | ✅ | 余弦 > 0.85 / 分数 > 0.7 |
| 同域召回（同一事件的其他报道） | ✅ | ⚠️ | reranker 会因「不回答 query」而归零 |
| **发现跨域关联（A 与 B 是同一件事）** | ❌ | ❌ | **两条路都失败** |
| 判断「这句是否引用了前面那条素材」 | ⚠️ | ⚠️ | 只在语义确实相近时有效，跨域引用抓不到 |

## 七、判据：什么时候该用余弦

**核心反转**：

> 常规 RAG：余弦高 = 相关 = 好。
> 素材关联/剪报：**余弦低 + 有明文理由 = 跨域命中 = 最好**。

因为同域关联是平凡的（「这条新闻和之前那条都属于政治」——不用机器做），
而真正有价值的是远距离拼接。所以在这类任务里：

```
关联的价值 ≈ 1 − cos(A, B)      （且必须有人写下的理由）
```

余弦在这里衡量的是「这条关联有多平凡」，**分数越高越不值得记**。

**推论：跨域关联不能指望向量发现，只能读人（或 LLM）写下的理由。**
文本里的「这就像」「同构」「并排」「与 X 的衔接」不是修辞，是唯一可落地的关联信号。

## 八、元教训

这件事的元意义不在「embedding 不行」，而在于**它是一次干净的「理论给假设、实测给定论」**。

- 理论上：跨域同构属于隐式语义空间的事，正是向量该表演的地方
- 实测：双塔排反了，交叉编码器直接归零
- 成本：两次 API 调用 + 六条文本

所以「有明确理论依据」这条原则要补一句：**理论只能给假设，能不能成立必须实测。**
后者往往是几行代码的事——省掉它，代价是拿一个方向错误的指标去做几百次判断。

**第二个教训**：诊断要分机制。看到 embedding 失败，很自然会想「换成 cross-encoder
会不会好」——这个推理听起来无懈可击（它确实能看到两段），但实测下来更糟。
**「换个更强的模型也许就行」是最容易骗过自己的推理。**

---

## 九、已知的边界与待补

- **已完成**（原第 2 条）：cross-encoder 已实测，**不行**（见 §三）。
- 两组实验都是**单点对照**（1 锚点 × 6 候选）。严格做法是 20 条正样本 vs 20 条负样本
  看分布是否能分开。但间隔一个为负、一个为零，方向已无悬念。
- **待做**：LLM 的造桥能力是否依赖实体知名度。「特朗普」「曹操」是高频实体，
  它见过大量关于它们的评论；换成自造概念或生僻名，同一结构还能不能连上？
  这条直接决定这套方法在冷门素材上可不可用。
- 更大模型的语义空间是否更好，未测。按 §五 的机制分析，**换更大的双塔模型大概无用**
  （结构问题不在容量），但这是推理，不是实测。
