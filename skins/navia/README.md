# navia（娜维娅）皮肤

浅底深字的竖版侧栏 ＋ 深底白字的横版主区 ＋ 毛玻璃面板，无视深浅主题设置。

## ⚠️ 本仓**不含**位图，背景请自备

原版皮肤用两张pixiv的同人图作底，**那两张图有版权，所以这里不发**。
不给图也能装：`patches.css` 里两处 `url()` 的**上一行都写死了兜底色**
（侧栏 `#e8e2da`、主区 `#201c15`），图缺失时自动退化成纯配色主题，不裂、不报错。

想要完整效果，自己把图放进 `assets/`：

| 文件 | 用途 | 建议 |
|---|---|---|
| `assets/sidebar.webp` | 侧栏底图 | **竖版**（贴顶对齐 `center top`） |
| `assets/main.webp` | 主区底图 | **横版**（居中 `center`） |

文件名必须一致（CSS 里就是这么写的）。原图的 `.jpg` 源料没有引用，不用放。

## 与发布版的两处差别

1. **`skin.json` 去掉了 `preview` 字段** —— 原预览图是含插画的截图，不随仓发布。
   后果：皮肤中心里这个皮肤可能显示**占位缩略图**（本机未实测确认，欢迎反馈）。
   想要缩略图就自己放一张 `preview/navia.jpg`，再把 `preview` 字段加回去。
2. `patches.css` / `skin.css` **一字未改**（只去图，不动代码）。

## 安装

把 `navia/` 整个目录放进 home 的 `skins/` 下（`<home>/skins/navia/`），重启后即可在皮肤中心看到。
